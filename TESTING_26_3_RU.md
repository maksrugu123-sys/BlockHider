# Ручное тестирование BlockHider — Minecraft 26.3

> Это план будущей проверки. Тесты ниже пока не отмечены как пройденные.

## Совместимость и базовое поведение
- [ ] Запуск только BlockHider.
- [ ] Запуск BlockHider вместе с BlockShape.
- [ ] Проверить, что блоки не удаляются из мира: коллизии, добыча и взаимодействия работают.
- [ ] Убедиться, что игроки и мобы остаются видимыми.
- [ ] Убедиться, что выброшенные предметы остаются видимыми.
- [ ] Проверить руки, предмет в руке, частицы и HUD.

## Независимые категории
- [ ] `/bhider category liquids off|on` — вода, лава и модовые жидкости.
- [ ] `/bhider category portals off|on` — Нижний портал, портал Края и End Gateway.
- [ ] Проверить особое значение порталов: End Portal видим по умолчанию; при OFF скрывается тоже.
- [ ] `/bhider category fire off|on` — огонь, костры и костры душ.
- [ ] `/bhider category plants off|on` — листья, цветы, культуры, саженцы и растения в горшках.
- [ ] `/bhider category special off|on` — сундуки, печи, колокола, головы и другие блок-сущности.
- [ ] `/bhider status` показывает фактические состояния.
- [ ] `/bhider reset` возвращает стандартные настройки.

## Перестройка геометрии
- [ ] После каждого переключателя проверить, что видимые чанки обновились без перезапуска мира.
- [ ] Проверить переключение стоя на месте.
- [ ] Проверить переключение рядом с границей чанков.
- [ ] Проверить после перехода в другой мир.

## Совместная работа с BlockShape
- [ ] Если BlockHider скрывает категорию, BlockShape восстанавливает её только при включённой соответствующей категории.
- [ ] Если категория выключена в обоих модах, она не должна появляться рядом с игроком.
- [ ] Если BlockHider включает категорию, видимость должна работать по всему радиусу отрисовки, а не только вокруг игрока.

**Отдельно контролировать выброшенные предметы: их поддержка не должна исчезнуть ни при каких переключателях категорий.**
