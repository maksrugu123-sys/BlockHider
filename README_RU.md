# Block Hider — Minecraft 26.3 / Fabric

Клиентский мод, скрывающий природные блоки и руды, но не удаляющий их из мира.

## Что скрывается
- Камень, булыжник, глубинный сланец и распространённые подземные породы.
- Земля, дерн, песок, красный песок, гравий, глина и грязь.
- Снег и лёд.
- Трава, папоротники, водоросли, лианы и лишайник.
- Все блоки из тега листвы Minecraft.
- Вода (лава остаётся видимой).
- Стандартные руды, включая варианты в глубинном сланце.

## Что остаётся видимым
Игроки, мобы, предметы, вазы, сундуки, механизмы, постройки и декоративные блоки.

## Как работает скрытие
- Блоки остаются в мире, твёрдыми и добываемыми.
- Скрытые цельные блоки не попадают в обычный цветовой рендер.
- Для открытых граней цельных блоков создаётся отдельная невидимая depth-маска: она записывает глубину, но не меняет цвет кадра. Поэтому скрытая стена продолжает закрывать блоки за собой.
- Нецельные модели растений скрываются без искусственной кубической маски, чтобы не создавать невидимые стены из травы.
- Всё работает на клиенте; серверная установка не нужна.

## Требования
- Minecraft Java 26.3
- Fabric Loader 0.20.1+
- Fabric API 0.165.2+26.3
- Java 25+

## Сборка
GitHub Actions собирает проект на Java 25 и Gradle 9.8. После успешной сборки JAR появится в артефактах Actions под именем `block-hider-26.3-fabric`.

**Важно:** перед установкой проверьте, что GitHub Actions завершился успешно, а затем протестируйте в Minecraft 26.3. Нужны тесты на границах секций, листьях, воде и блоках-соседях.
