# Block Hider — Minecraft 26.3 / Fabric

Клиентский мод для скрытия выбранной природной геометрии и стандартных руд без удаления блоков из мира.

## Что скрывается
- Камень, булыжник, глубинный сланец и распространённые подземные породы.
- Земля, дерн, песок, красный песок, гравий, глина и грязь.
- Снег и лёд.
- Трава, папоротники, водоросли, лианы и лишайник.
- Все блоки из тега листвы Minecraft (в том числе варианты деревьев).
- Вода — через отдельный рендерер жидкостей; лава не скрывается.
- Стандартные руды: уголь, железо, медь, золото, редстоун, лазурит, алмазы, изумруды и кварц Незера, включая варианты в глубинном сланце.

## Что остаётся видимым
Игроки, мобы, предметы, вазы, сундуки, механизмы, постройки и декоративные блоки не входят в список скрытия.

## Важно
- Блоки не удаляются из мира и остаются твёрдыми: по ним можно ходить, их можно добывать.
- Скрытие визуальное и работает только на клиенте.
- Серверная установка не нужна.
- Список блоков задан в `HiddenBlocks.java`; вода отдельно отключается в `FluidRendererMixin.java`.

## Требования
- Minecraft Java 26.3
- Fabric Loader 0.20.1+
- Fabric API 0.165.2+26.3
- Java 25+

## Сборка
GitHub Actions собирает проект на Java 25 и Gradle 9.8. После успешной сборки JAR появится в артефактах Actions под именем `block-hider-26.3-fabric`.

Локально: `gradle build`.

**Важно:** пока не подтверждены успешная сборка и запуск в игре. Текущий способ скрытия моделей не создаёт невидимую depth-mask, поэтому блоки за скрытой поверхностью могут просвечивать. Это отдельная незавершённая задача рендеринга.
