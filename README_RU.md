# Block Hider — Minecraft 26.3 / Fabric

Клиентский визуальный мод: скрывает почти весь мир, оставляя видимыми мобов, игроков, выброшенные предметы, частицы и портал в Энд.

## Что скрывается
- Все обычные блоки, включая рамку портала в Энд, постройки, руды, сундуки и механизмы.
- Все жидкости: вода, лава и другие жидкости.
- Все блок-сущности, кроме самого портала в Энд.
- Сущности, кроме мобов, игроков и выброшенных предметов: транспорт, снаряды и прочие объекты.
- Энд-гейтвей скрывается; сохраняется именно блок обычного портала в Энд.

## Что остаётся видимым
- Мобы и их модели.
- Игроки, включая локального игрока.
- Выброшенные предметы на земле.
- Руки игрока и предмет в руке от первого лица.
- Частицы.
- Сам портал в Энд.

## Важно
- Меняется только клиентское отображение.
- Блоки и сущности не удаляются из мира: коллизии, добыча, взаимодействия и логика мира не изменяются.
- Это не удаление файлов текстур из Minecraft, а отключение рендеринга выбранных объектов.
- HUD, прицел и интерфейс не изменяются.
- Depth Mask в этой версии не используется.

## Требования
- Minecraft Java 26.3
- Fabric Loader 0.20.1+
- Fabric API 0.165.2+26.3
- Java 25+

## Сборка
GitHub Actions собирает проект на Java 25 и Gradle 9.8. После успешной сборки JAR появится в артефактах Actions под именем `block-hider-26.3-fabric`.

**Важно:** успешная сборка подтверждает только компиляцию. Для подтверждения поведения необходим запуск в Minecraft 26.3 и проверка портала, мобов, игроков, выброшенных предметов, блок-сущностей и жидкостей.


## Управление категориями

Категории можно переключать независимо, не выключая весь мод:

- `/bhider` или `/bhider status` — показать текущие настройки.
- `/bhider category liquids on|off` — жидкости.
- `/bhider category portals on|off` — порталы.
- `/bhider category fire on|off` — огонь и костры.
- `/bhider category plants on|off` — растения, листья и культуры.
- `/bhider category special on|off` — специальные модели и блок-сущности.
- `/bhider reset` — вернуть стандартные настройки.

`on` возвращает категорию в обычный рендер Minecraft по всему миру; `off` оставляет её скрытой. При совместной установке BlockShape может восстанавливать скрытые текстуры рядом с игроком. Чтобы отключить и это локальное восстановление, выключи ту же категорию командой `/bshape category ... off`. End Portal по-прежнему остаётся видимым для совместимости.

Настройки сохраняются в `config/block-hider.properties`. По умолчанию жидкости остаются видимыми, если установлен BlockShape; остальные новые категории выключены, чтобы сохранить прежнее поведение.
