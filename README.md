# Block Hider

Client-side Fabric visual filter for Minecraft 26.3. Hides world blocks, fluids, most block entities, and non-mob/non-player entities except dropped item entities. Mobs, players, dropped items, first-person hands, particles and the End Portal remain visible.

The mod changes rendering only; it does not remove world data or alter collision and gameplay logic.

See [Russian README](README_RU.md) for details and build instructions.
